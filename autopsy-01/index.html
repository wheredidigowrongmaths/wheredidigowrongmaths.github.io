MISTAKE AUTOPSY #1
Most students write this 👇
(a + b)² = a² + b²
✖ WRONG
Test it with numbers
a = 3
b = 4
(a + b)² = (3 + 4)² = 7² = 49
a² + b² = 3² + 4² = 9 + 16 = 25
49 ≠ 25
So, (a + b)² ≠ a² + b²
Let's find where it went wrong 🔍
The square (a + b)²
Wrong formula counts only a² + b²
Forgotten: ab + ab = 2ab
The correct rule ✅
(a + b)²
Substitute
a = 3, b = 4
= a² + 2ab + b²
=
9
+
24
+
16
= 49 ✅
Why does the brain slip?
(ab)² = a²b² ✅
(a + b)² ≠ a² + b² ✖
(a + b)² = a² + 2ab + b² ✅
Squares spread over ×
NOT over +
